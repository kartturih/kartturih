# Hi, I'm Arttu 👋

I'm a final-year ICT engineering student and junior software developer from Finland.

C++ is my main technical foundation, while my projects have also given me practical experience in mobile development, artificial intelligence, real-time networking, databases and game technology. I enjoy learning new technologies and building software from idea to implementation.

## Current projects

### Fishing App

A Flutter application for fishing trip planning, catch logging and personal fishing statistics.

The project includes:

- Interactive vector maps and Finnish bathymetry data
- Offline map data
- Catch logging with photos, locations and lures
- Personal tackle box and searchable lure catalogue
- Statistics and catch filtering
- Drift and SQLite persistence
- Repository-based architecture
- Automated testing

[View the repository](https://github.com/kartturih/fishing-app)

### Neuroevolution Car Simulation

My C++ thesis project exploring how neural networks and evolutionary algorithms can teach simulated cars to navigate a 2D track.

The project includes:

- Neural-network-controlled agents
- Distance sensors and normalized observations
- Genome and phenotype representations
- Structural mutations and innovation tracking
- Real-time simulation and visualization
- Fitness-based evolutionary training

[View the repository](https://github.com/kartturih/oppari)
